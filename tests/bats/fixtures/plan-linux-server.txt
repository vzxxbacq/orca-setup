Optional modules (add to --apply):
  --power         Use sudo to mask the systemd sleep targets; remind you of the BIOS power-loss setting.
  --containers    Install Docker Engine from Docker's apt repository if missing; add you to the docker group.
  --apple         macOS only: skipped on Linux with a notice.
  --android       Install Android platform tools if missing.
  --media         Install PDF/media processing helpers if missing.
  --agent-gemini  Install the Gemini CLI if missing (optional; not usable with personal accounts).
Authentication (interactive, run on their own):
  --auth-gh       GitHub device-code login: open https://github.com/login/device on any device and enter the code gh shows; an existing valid login is kept.
  --auth-codex    Add a Codex account to this host's Orca using device authentication.
  --auth-claude   Add a Claude account to this host's Orca (interactive), unless one is selected.
  --auth-agy      Start agy to sign in to Google; over SSH it prints a URL to open elsewhere and asks for the code. Needs an unlocked Secret Service keyring to keep the session.
  --auth-linear   Print Linear's API settings URL (open it on any device); read a key without echoing or logging it.
  --check         Show baseline and authentication readiness, without printing credentials.
Existing installations and user configuration are preserved. SSH is never configured.
